# Omarchy app profile — what scripts/omarchy-apply.sh keeps installed on an
# Omarchy machine (the ThinkPad). Additive only: deleting a line never
# uninstalls anything (use `omarchy pkg drop <pkg>` / Remove > Web App).
#
# Derived 2026-11-24 from rouven-m5-pro's Homebrew casks and pwas.txt, checked
# against Omarchy 4's own defaults (install/omarchy-base.packages + the web apps
# it ships) and the Arch / AUR package indexes. NOT repeated here because
# Omarchy installs them itself: Google Chrome, Obsidian, LocalSend, LibreOffice,
# Docker, mise, Neovim, herdr, Superwhisper, mpv, Disktree, and the web apps
# ChatGPT, Grok, WhatsApp, X, YouTube, Zoom, Discord, Google apps, HEY, Basecamp.
#
# One entry per line, fields separated by `|`:
#   pkg     | <arch package>                       official repos or Omarchy's repo
#   aur     | <aur package>                        built by yay; not vetted by Arch
#   omarchy | <omarchy-install-* command [args]> | <package> or app:<launcher name>
#           Omarchy's own installer (adds extensions, bar plugins, services);
#           the third field is how we know it already ran.
#   webapp  | <launcher name> | <https url> [| <https icon url>]
#           icon omitted = fetched from the site.
